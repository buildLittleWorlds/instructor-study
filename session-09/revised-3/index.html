The paper move · what the experiment changes

The music is not inside the glider.

This app performs a sonification: it turns selected features of data into sound through an explicit, authored mapping. A glider has no natural pitch, instrument, or rhythm. Row could have controlled timbre instead of pitch; column could have controlled duration instead of stereo position. Another mapping would make another music.

That contingency is not a defect. It creates a second individuation experiment. Hear the board treats absolute location as meaningful. Hear the pattern removes translation and treats internal relation as meaningful. Both use the same cellular history. What changes is the level at which the history is described.

Dennett’s account of real patterns helps name the wager: a higher-level description earns its place when it compresses events and supports prediction. The repeated glider phrase does not prove that the glider is an additional object or that cognition works like Life. It lets the reader hear what becomes stable when one kind of variation is ignored.
