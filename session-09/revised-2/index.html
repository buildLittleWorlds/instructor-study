Nothing moves. Something travels.

A glider does not cross the board by carrying its cells with it. It becomes the next glider, and then the next. What if memory also persists by being generated again?

The proposition to test

The glider is not transported. It is regenerated.

No cell contains it. Conway’s rule does not store its journey. The moving thing appears in the relation among successive boards.

The interpretive turn

A whole can exist only as it unfolds

Barenholtz’s autoregressive proposal adds more than the familiar observation that memory is imperfect. It asks whether the remembered content was ever stored as a finished, replayable thing.

1 · Present context

A state, not a journey

The board contains the current arrangement. In Barenholtz’s proposal, a cue and learned parameters constrain what can be generated now.

2 · Local production

One next element

Conway’s rule produces one next board. An autoregressive system produces one next element rather than retrieving an already completed sequence.

3 · Feedback

The output becomes context

The new board becomes the next input. Repetition creates an extended coherence that no single step contains in advance.

Where the analogy earns its place

Persistence without transport

No glider-object passes from cell to cell. No future trajectory is stored on the board. A familiar higher-level organization emerges through dependable continuation. This makes Barenholtz’s alternative to the archive metaphor visible.

Where the analogy must stop

A fixed rule is not learned memory

Conway’s deterministic rule is supplied from outside and the complete current board is retained. Barenholtz’s stronger autogeneration proposal concerns a continuation function recoverable from a domain’s statistical structure. The glider illustrates autoregressive unfolding; it does not establish a theory of human memory.

Second encounter · change the kind of trace

From exact continuation to imperfect remembrance

The glider regenerates under an exact rule. Musical memory is less obedient. Hear one original figure by itself and in changing surroundings, then use the comparison to imagine a generator working from only a degraded trace.

Paper argument · three pressures

What kind of reality does regeneration make?

Dennett: the pattern is real

“Glider” is a useful higher-level description because it compresses cellular activity and supports prediction. A pattern need not be an additional material object in order to earn explanatory reality.

Barenholtz: the content is made now

What appears to be retrieval may be context-sensitive generation shaped by learned parameters. Stability could consist in reliably producing related continuations, not reopening the same stored representation.

Generative-memory research: keep constraints

Generative reconstruction need not mean that nothing is encoded. Models such as Spens and Burgess retain hippocampal encoding and replay while explaining how schemas reconstruct predictable structure.

V3’s provisional claim: the glider suggests that continuity can be real without being transported or stored as a completed whole. It gives us a way to imagine Barenholtz’s proposal, not evidence that minds implement Conway-like rules or contain no memory traces.
A short shelf

Sources that separate the claims

  • Daniel Dennett, “Real Patterns” (1991) — why gliders and beliefs may be real as compressive, predictive patterns.
  • Elan Barenholtz, “Memory Isn’t Real (Part 1)” (2025) — the accessible statement of memory as just-in-time generation rather than retrieval of a finished representation.
  • Barenholtz, “Memory Isn’t Real (Part 2)” (2025) — function, feedback, and the claim that an extended sequence need not be stored in advance.
  • Barenholtz, “Autogeneration” (2025) — the stronger proposal that a continuation function can be recovered from a domain’s internal statistical structure.
  • Eleanor Spens and Neil Burgess, “A generative model of memory construction and consolidation” (2024) — an open, peer-reviewed model combining generative reconstruction with encoding and replay.
